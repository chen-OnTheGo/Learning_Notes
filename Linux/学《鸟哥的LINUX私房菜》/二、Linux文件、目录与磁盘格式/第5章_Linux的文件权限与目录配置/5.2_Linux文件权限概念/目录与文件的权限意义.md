
文件权限对于一般文件与目录文件有何不同？

## 权限对文件的重要性

文件是实际含有数据的地方（文本文件、数据库文件等）。因此，权限对文件的意义：
- r (read)：可读取该文件的实际内容。
- w (write)：可以编辑、新增或修改该文件的内容（==不包括删除该文件==）。
- x (execute)：该文件具有可以被系统执行的权限。

关于判断文件是否可执行，Windows和Linux的判断方法是不同的——
- Windows下面一个文件是否能被执行是借由其**扩展名**来判断。例如：`.exe`、`.bat`、`.com`等。
- Linux下面一个文件是否能被执行是借由**是否具有`x`这个权限**来决定，跟文件名是没有绝对关系的。

所以，对于文件的`rwx`来说，主要都是针对文件的内容而言，与文件名的存在与否没有关系，因为文件记录的是实际的数据。

## 权限对目录的重要性

文件是存放实际数据的所在，那目录主要存储什么？目录主要的内容在记录文件名列表。文件名与目录有着强烈的关系。那针对目录，权限有什么意义？
### r (read contents in directory)

表示具有读取目录结构列表的权限，也就是可以查询该目录下的文件名数据，例如`ls`命令。

### w (modify contents of directory)

表示具有改动该目录结构列表的权限 ——
- **建立**新的文件与目录
- **删除**已经存在的文件与目录（不论该文件的权限是什么）
- 将已存在的文件或目录进行**更名**
- **移动**该目录内的文件、目录位置

### x (access directory)

目录不可以被执行，目录的`x`代表的是用户能否进入该目录成为工作目录的用途。这里的”工作目录“（work directory）就是我们目前所在的目录。

变换目录的命令是`cd`

## 理解

可以这样说，假设文件是一堆文具盒，所以可以在上面写 / 改一些数据；
而目录则是一堆抽屉，可以将文件盒分类放置到不同的抽屉里，因此抽屉最大的目的是拿出 / 放入文具盒。
目录的`x`权限，就相当于该命令 —— 也就是该抽屉的”钥匙“，有钥匙才能打开抽屉。

## 注意

需要注意的是，能不能进入某个目录，只与该目录的`x`权限有关。此外，工作目录对于命令的执行非常重要，如果你在某目录下不具有`x`的权限，那么你就无法切换到该目录下，也就无法执行该目录下的任何命令，即使你具有该目录的`r`或`w`权限。

若要开放目录给任何人浏览时，应该至少也要给予`r`及`w`的权限，但`x`权限不可以随便给，下面是一个例子：

假设有个账号名为`dm`，它的家目录在`/home/dm/`，`dm`对此目录具有`rwx`的权限，若在此目录下有个名为`the_root.data`的文件，该文件的权限如下：
```
-rwx------ 1 root root 4365 Sep 19 19:55 the_root.data
```
则`dm`对此文件的权限是什么？可否删除此文件？

理解：假如我是`dm`，我有个抽屉`/home/dm`，因为我对这个抽屉有`rwx`的权限，所以我可以处理删除这个抽屉里面的东西，现在有个人，叫`root`，他把他的文件盒放在了我的抽屉里面，由于我对这个文件盒来说是others身份，所以我无法查看打开这个文件盒，但是我却可以直接把这个文件盒扔掉（删除）。
所以结论是：`dm`这个用户可以删除`the_root.data`文件。
