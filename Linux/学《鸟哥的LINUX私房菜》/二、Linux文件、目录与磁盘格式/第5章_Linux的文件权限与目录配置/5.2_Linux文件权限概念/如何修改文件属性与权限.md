
如何修改一个文件的属性与权限？有多少文件的权限我们可以修改？。我们先接晒哦几个常用于用户组、拥有者、各种身份的权限之修改的命令：
- `chgrp`：(change group)修改文件所属用户组。
- `chown`：（change owner）修改文件拥有者。
- `chmod`：修改文件的权限，SUID、SGID、SBIT等的特性。


## 修改所属用户组——`chgrp`

修改的前提是，要被修改的组名必须在`/etc/group` 文件中存在，否则会显示错误。

指令：
```
chgrp [-R] dirname/filename

-R: 进行递归(recursive)修改，亦即连同子目录下的所有文件、目录都更新成为这个用户组之意，常常用在修改某一目录内所有的文件。
```

例子：输入`chgrp lc vmlinuz-6.14.0-36-generic`

## 修改文件拥有者 —— `chown`

需要注意的是，用户必须是以及存在系统中的账号，也就是在`/etc/passwd`这个文件中有记录的用户名称才能修改。

`chown`还可以顺便直接修改用户组的名称。此外，如果要连目录下的所有子目录或文件同时更改文件拥有者的话，直接加上`-R`的选项即可。
语法如下：
```
chown [-R] 账号名称 文件或目录
chown [-R] 账号名称：用户组名称 文件或目录
```

例子：

（事实上，`chown`也可以使用`chown user.group file`，也就是在拥有者与用户组间加上小数点。不过有些人设置账号时，若在账号当中加入小数点，就会造成系统的误判，所以建议用冒号`:`
此外，`chown`也能单纯的修改所属用户组，例如`chown .sshd initial.cfg`）

那么一般什么情况下会使用`chown`或`chgrp`?

最常见的例子就是在复制文件给你之外的其他人时：
假如我今天要将`.bashrc`这个文件复制成`.bashrc_test`文件名，并且给`bin`这个人。就可以这样做：
```
cp .bashrc .bashrc_test
```

由于复制操作`cp`会复制执行者的属性与权限，执行上述指令后`.bashrc_test`还是属于`root`所拥有，这样一来，即使将`bashrc_test`文件拿给`bin`用户，它仍然无法修改，所以这时我们就需要将这个文件的拥有者与用户组修改一下。

PS：上述`cp`命令语法如下：
```
cp 源文件 目标文件
```


## 修改权限 —— `chmod`

权限的设置方法有两种，分别可以用数字或符号来进行权限的修改。

### 数字类型修改文件权限

我们已经知道文件的权限字符为`-rwxrwxrwx`，这九个权限是三个三个一组的。其中，我们用数字来代表各个权限：
```
r : 4
w : 2
x : 1
```

每种身份（owner、group、others）各自的三个权限（r、w、x）数字是需要累加的。例如`-rwxr-----权限的数字则是：
```
owner = rwx = 4 + 2 + 1 = 7
group = r-- = 4
others = --- = 0
```

修改权限的命令`chmod`的语法：
```
chmod [-R] xyz 文件或目录
```
（这里面的`xyz`就是三位权限数字）

### 符号类型修改文件权限

我们已经知道的是，基本上就九个权限分别是`user`、`group`、`others`三种身份，那么就可以借由`u`、`g`、`o`来代表三种身份的权限，此外，`a`则代表all即全部的身份
