
## 开始执行命令

可以这样执行命令：
```
command [-options] argument1 argument2 ...
```

其中，`command`为命令名称。

一行命令中第一个输入的部分绝对是命令(command)或可执行文件（例如shell脚本）。

中括号`[]`不存在实际的命令中，仅表示这个是可选的。加入选项设置时，通常选项前会带`-`号，有时候会使用选项的完整全名，则选项前带有`--`符号。

`parameter1`、`parameter2`等是`command`的参数。

空格是很重要的特殊字符，命令、选项等中间以空格来区分，不论几个空格都视为一格。

==命令太长的时候，可以使用反斜杠`\`来转义回车键==，使命令连续到下一行，需要注意的是，反斜杠后就立刻接着特殊字符才能转义。

区分字母大小写。
