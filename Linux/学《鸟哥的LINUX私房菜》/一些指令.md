
Linux默认的情况下会提供六个终端来让用户登录，切换方式为：
```
Ctrl + Alt + F1 ~ F6
```

虚拟窗口由全屏模式返回窗口模式：
```
Host + F
```
这里的`Host`表示`Right Ctrl`。

中断目前程序：
```
Ctrl + c
```

直接离开命令行模式，相当于输入`exit`：
```
Ctrl + d
```

求助说明：
```
command --help
```
其中`command`是指令名称。此句用于查询对应指令的用法和选项参数的说明。

若要使用的是从来没有用过的命令，或者要查文件的格式，就通过`man page`命令：
```
man command
```
其中`command`是指令名称。

还有两个命令与man page有关，这俩个命令是`man`的简略写法：
`whatis [命令或文件]`  和  `apropos [命令或文件]`
