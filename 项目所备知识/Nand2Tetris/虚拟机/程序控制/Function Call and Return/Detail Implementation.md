![](../../../../../img/Pasted%20image%2020260225212057.png)

上图中的`Foo.main`是指在`Foo`类中的`main`函数；`Bar.mult`是指`Bar`类中的`mult`函数。

如果这是编译的Jack语言的代码，则会存在两个分别名为`Foo`和`Bar`的不同类文件，但是，一旦所有内容都编译成VM code，我们就失去了“类”的概念，得到的只是一长串具有全名的函数 —— `类名.函数名`。

上图中的`Foo.main`函数是`caller`，`Bar.mult`函数是`callee`，接下来我们分别从这两个函数的角度去描述：
