
在二分查找中，左指针和右指针的移动可以说都是以mid来做参照物。而mid的求值就是通过计算左指针和右指针距离的中点那个地方。“直译”的话就是：
```
int mid = (left + right) / 2;
```

但题解中却是这样计算`mid`的：
```
int mid = ((right - left) >> 1) + left;
```

看似是两个同义句，但其实是有区别的。
核心区别就是：是否可能溢出。

如果用第一种“直译”的方法，若其中的`left`和`right`的值都特别大，再加起来，就可能会超过`int`类型的最大值，从而造成溢出。

而第二种方法先计算`right`和`left`的区间长度，自然不会超过数组的长度，也不会超过`int`类型的范围，接着再右移一位，相当于除以2，再加上`left`。这种方法避免了两个值特别大的数相加，避免了溢出，更安全。
