
自己尝试了，没做出来，看完题解后，认为没做出来的原因之一就是对题的理解不到位。

我没理解的地方是：在一天中可以既买股票一次，也能卖股票一次。（我以为在某天卖了股票后，就只能在第二天买股票）
其实题目中也指出了这点：

> 你可以在同一天==多次买卖==该股票，但要确保你持有的股票==不超过一股==。

## 核心思想

然后题解中给的解决方法的核心在于，就算是在第一天买入第四天买出，也可以将其看作是一个连续天数的行为——也就是利润是可以分解的。

假如第0天买入第3天卖出，首先想到的计算方式是：
`prices[3] - prices[0]`
但是，利润是可以分解的，所以上面这个式子也等效于：
```
prices[3] - prices[2] + prices[2] - prices[1] + prices[1] - prices[0]
```
即：
```
(prices[3] - prices[2]) + (prices[2] - prices[1]) + (prices[1] - prices[0])
```
这样就可以将其分解成连续的行为：第0天买入，第1天卖出再买入，第2天卖出再买入，第3天卖出。

所以就只需要将每种连续两天的利润算出来，再将正利润（利润大于0）的值加起来，就是最大利润了。
