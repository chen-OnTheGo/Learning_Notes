## 优秀解法

看到评论区一个更优秀的解题过程：

首先，需要知道的是，计算每个加油站剩余gas（提供的gas - 消耗的gas），若所有加油站剩余的gas之和小于0，则一定无法行驶一周；翻之，和大于等于0，就一定能行驶一周。（这个想法我也想出来了，但没想好怎么利用）
接着，就是寻找开始的点，思路是，若当前的加油站剩余gas小于0，开始的点的索引就为当前加油站的往后一步的索引。
遍历一遍后，就能找到开始点。最后可以直接通过所有加油站剩余的gas来判断是否能行驶一周，就不用从头到start点又遍历一次了。

下面是这个答案：
```
class Solution {
    public int canCompleteCircuit(int[] gas, int[] cost) {
        int start = 0;
        int sum = 0;
        int n = gas.length;
        int curGas = 0;

        for (int i = 0; i < n; i++) {
            sum += gas[i] - cost[i];
            curGas += gas[i] - cost[i];

            if (curGas < 0) {
                start = i + 1;
                curGas = 0;
            }
        }

        return sum < 0 ? -1 : start;
    }
}
```
